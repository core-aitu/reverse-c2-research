# Management API. Доказанный контракт чтения документации

| Элемент | Установленное поведение |
|---|---|
| Запрос | ApiClient сформировал GET /Documentation. На стороне сервера найдены шаблон [controller] и атрибут GET у административного действия. Метод и путь непосредственно наблюдал перехватчик HttpMessageHandler. |
| Успешный ответ | HTTP 200 с массивом объектов. Реальный клиент прочитал поля name, contents, children, включая вложенные элементы. Пустой массив дал пустую коллекцию. Порядок разных документов не закреплён как часть контракта. |
| Ошибочные ответы | При 200 с JSON null и при 503 клиент завершил вызов исключением SpecterInsight.ApiClient.ApiException. Вывод относится к этим двум входам. |
| Граница проверки | Серверная DLL сформировала дерево. Тестовый код сериализовал его в JSON и подал клиенту через обработчик в памяти. Маршрутизация Kestrel, сетевой транспорт, согласование версии и проверка прав в этот прогон не входили. |

В серверной сборке выявлены 39 типов-кандидатов по имени Controller и пространству имён. Количество типов и атрибутов не равно количеству маршрутов, доступных конкретному пользователю. Подробный поведенческий контракт установлен для чтения документации. FND-006, FND-007, FND-008, FND-012.
