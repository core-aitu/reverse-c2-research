**Охват методов.** Для каждого образа числитель выборочной проверки IL и полный знаменатель MethodDef приведены в coverage.json. У 13 514 аксессоров дополнительно подтверждена простая операция с полем. Структурные ILSpy-проверки закрыты для 44/44 серверных файлов (67 MethodDef, 184 места) и 3/3 UI-файлов (18 мест). Предметная статическая спецификация отдельно закрыта для pipeline 117/117, services 73/73, REST 202/202, Obfuscation 837 TypeDef/7 673 MethodDef, 22/22 modules, четырёх Beacon variants и 24/24 UI workflow с semantic review 152/152 Service/Utility/ViewModel-файлов. Runtime-свойства не выводятся из полноты статического индекса. Для нативных компонентов зафиксированы байтовая идентичность и распознанный формат; полная семантика нативных реализаций не установлена.
