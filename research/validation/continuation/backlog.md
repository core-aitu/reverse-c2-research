# Задачи продолжения и исходная точка

Исходная точка — 21 OBS, 27 FND и 56 индивидуальных записей IL (Server 29, Host 3, UI 21, ApiClient 3). Неизменённые карточки доступны в [исходном разборе](../../analysis/method-evidence.json). Результаты этого этапа добавляются отдельно.

| Задача | Объект и исходное свидетельство | Проверяемый переход или критерий |
|---|---|---|
| 1 | Все образцы, OBS-013/014 | Сохранить базу и дать раздельные показатели шести уровней |
| 2 | Пять управляемых вариантов, OBS-015 | Отдельные IL-карточки LogEntry, поля и проверка граничных значений |
| 3 | Восемь нативных вариантов и 22 модуля, OBS-003/010 | Отдельные идентичности и зависимости с указанием силы доказательства |
| 4 | Server.Host и Server, OBS-005/009 | Build → регистрация → потребители документации и аудита |
| 5 | DocumentationController и ApiClient, OBS-006/007 | Пять действий, настоящий HTTP для чтения, успех и отказ |
| 6 | UI, OBS-006/017 | Присоединение окна, обновление и отображение документов и событий |
| 7 | Server, ApiClient, UI и PostgreSQL, FND-013/016 | Коррелировать сохранение, передачу, получение и отображение |
| 8 | Наблюдения Specter, OBS-012 | Атрибутированный существующий захват |
| 9 | Ресурсы, OBS-018–021 | Обнаружить последнего подтверждённого потребителя, проверить поведение на фикстурах |

## Состояние после проверки

| № | Статус | Результат и остаток |
|---|---|---|
| 1 | Выполнено | Шесть уровней и 32 образа с хешами в matrix.json. Старые 56 записей сохранены. |
| 2 | Выполнено для диагностики | 5/5 образов, 65 карточек, динамика на каждом. 13 привязок метода к исходнику для единственного подходящего PDB. |
| 3 | Выполнено для статической атрибуции | 8/8 уникальных PE и 22/22 модуля. Загрузка во время реальной сессии остаётся Unverified. |
| 4 | Частично | Найдены прямые регистрации обеих служб. Прямой переход в отдельный Startup и полный путь установки не установлены. |
| 5 | Частично | 5/5 действий классифицированы. Реальный продуктовый фильтр дал 401. Успех чтения и поиска проверен на явно отделённых стендовых маршрутах. Для положительного вызова настоящего защищённого маршрута нужна штатная авторизация. |
| 6 | Выполнено на стенде | Оба штатных контрола показывались в Xvfb. Успех, пустой ответ, ошибка после загрузки и повторное открытие зафиксированы. |
| 7 | Выполнено для лабораторной цепочки, частично для установки | Событие прошло по сети до строки окна и совпало с SQL-записью. Привязку соединения к ApiClient и подписчика к UI выполнил стенд. Нужны штатный вход и схема реальной установки. |
| 8 | Ожидает внешнего материала | Поиск по именам повторён. Нового захвата нет, историческая сессия остаётся Unverified. |
| 9 | Выполнено для двух целевых опытов | Резервный поиск дошёл до возвращаемого результата. Усечение поля CSV дошло до свойства объекта у потребителя. Каталоги и сборки распределены в матрице. Реальный импорт Kibana, содержимое зашифрованных вложений и визуализация поля производителя остаются открытыми. |
