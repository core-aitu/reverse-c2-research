# Формы записей исследования

| Запись | Поля |
|---|---|
| Артефакт | ART, относительный путь, тип, размер, SHA-256, источник получения и группа совпадающего содержимого. Для недоступного содержимого — причина. |
| Наблюдение | OBS, вид наблюдения, исходные ART, инструмент и версия, параметры, локатор, файл результата и границы применимости. Время UTC при наблюдении исполнения. |
| Метод | Компонент, SHA-256 сборки, MVID, полное имя, сигнатура, токен, смещение IL, входы и результат, вызовы, изменение состояния, обработка ошибок, OBS, статус и основание для уверенности. |
| Опыт | Входная фикстура, сборки и среда, границы стенда, ожидаемое значение, наблюдаемое значение, критерий совпадения, запись повторного прогона и расхождения. |
| Вывод | FND, проверяемое утверждение, статус, ссылки на OBS, ограничения и возможное свидетельство для повторной оценки. |
