## Контракт transforms и форматы

`BaseTransformer` задаёт узел ориентированного pipeline; `AbstractTransformer<TIn,TOut>` принимает результаты родительских узлов и возвращает typed result. Строковые узлы используют `StringTransformResult` (`string` плюс `EmbeddedFiles<string, byte[]>`), бинарные — `ByteTransformResult` (`byte[]`). Объявленные payload formats: `None`, `Any`, `PowerShell`, `CSharp`, `DotNetExe`, `DotNetDll`, `DotNetService`, `DotNetNativeExe`, `WindowsCommand`.

| Путь | Вход → выход |
|---|---|
| `Roslyn` | C# source -> CSharpCompilerTransformer -> managed PE bytes |
| `BFlat` | C# source -> temporary .cs -> bflat build -> native PE/ELF bytes |
| `Zig` | Zig source plus EmbeddedFiles -> zig build-exe/build-lib -> binary bytes |
| `ZigShellcode` | Zig binary -> zig objcopy .text -> raw shellcode bytes |
| `CSharpToPowerShell` | C# source -> Add-Type text or embedded managed assembly -> PowerShell source |

Связь с сервером подтверждена ссылками на transform-типы из `PayloadPipelineService`, `ObfuscationService`, PowerShell runspace/session services, compiler cmdlets и Specter-specific builders. Поле `pipeline_and_compiler_links` полного JSON-каталога содержит точные server-файлы для каждого типа.
