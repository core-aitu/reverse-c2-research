# Аудит исследовательских свидетельств

Это исторический результат первого аудита 18 ноября. Следующий статический разбор оформил три новые карточки и изменил текущие счётчики. Сохранённый JSON этого аудита не переписан. [Актуальное дополнение](documentation-ui-semantics.md)

Проверка выполнена 18 ноября 2026 года по местному времени. Точное время UTC записано в [машинном результате](../validation/continuation/evidence-audit.json). Проверялись текущие файлы репозитория и локальные архивы. Бинарные компоненты продукта при аудите не выполнялись.

## Подтверждено повторно

- Проверка continuation/verify.py прошла на исходном каталоге SpecterInsight. Совпали хеши выбранных образцов и сохранённые результаты трёх серий продолжения. Эта команда не пересчитывает полный манифест поставки.
- Сохранены два одинаковых журнала диагностики по 38 записей, два сетевых журнала по 19 записей и два журнала экранов по 9 записей. Побайтное совпадение подтверждает состояние сохранённых файлов. Свежий повтор исполнения не проводился.
- Все ссылки FND на OBS разрешаются. Файлы из поля records наблюдений существуют. Уникальность идентификаторов проверена. Смысловая обоснованность каждого вывода требует отдельной проверки содержания.
- 56 исходных и 65 дополнительных записей дают 121 уникальную идентичность SHA-256/MVID/токен.
- Контрольные суммы локального архива среды и RPM Xvfb совпали. Чтение каталога TAR прошло успешно, в нём присутствуют SDK и PostgreSQL. Среда не извлекалась и не запускалась.

## Исправленное покрытие

Счётчик 121 ранее находился внутри категории Method Semantically Analyzed. Индивидуальные записи содержат метаданные и IL, но не задают проверенную связь со всеми обязательными полями семантической карточки каждого метода. Групповое описание LogEntry не завершает оформление индивидуальных карточек. В матрице теперь разделены 121 запись IL, 65 методов с групповым описанием диагностического поведения и пока не установленное число полных семантических карточек. Значение null означает отсутствие законченного подсчёта.

Проверяющий скрипт требует явное passed=true у проверок, где это поле предусмотрено форматом. Удалённое поле больше не считается успешным. Добавлены проверки дубликатов идентификаторов. Запуск Python с отключёнными assert отклоняется.

Шесть регрессионных тестов прошли. Проверены исходные журналы, удалённый признак успеха, ложное и не-логическое значение признака, дубликаты, пустые журналы и запуск с отключёнными assert. Тесты работают с копиями записей в памяти и не меняют исторические журналы.

В итоговом отчёте обновлены строки о клиенте и доставке событий. Они учитывают лабораторный результат продолжения и сохраняют открытым поведение штатной установки. В инструкции воспроизведения исправлена исходная директория команд после переноса research в отдельный репозиторий.

## Незавершённые части

| Область | Граница имеющегося результата |
|---|---|
| Семантическое покрытие | Полные карточки входов, результата, состояния, ошибок и свидетельств не проверены для каждого учтённого метода. |
| Административное приложение | Нет успешного штатного входа, полного запуска оригинальных Host/UI и проверки всех административных сценариев. Стендовые маршруты и подключения явно выделены. |
| События и хранение | Лабораторная доставка подтверждена. История миграций и восстановление соединения на действующей установке остаются непроверенными. |
| Beacon и модули | Исследованы происхождение, диагностическая запись и зависимости. Полного поведенческого описания импланта нет. |
| Историческая установка | Нет атрибутированного захвата обмена и эталонной выгрузки БД. |
| Среда повторения | Временный стенд отсутствует. Архив доступен локально и исключён из Git. Свежая сборка и исполнение из архива не проверены. |
| Версия и ресурсы | Нет эталонного предыдущего выпуска, проверки реального импорта Kibana и содержимого трёх зашифрованных вложений. |

Полная репродукция SpecterInsight этим корпусом не подтверждается. Дальнейший допустимый анализ охватывает защитное описание, происхождение, диагностику и административные функции. Реализация рабочего импланта, диспетчера постэксплуатационных задач и операционного канала C2 в этот результат не входит.

## Повторение аудита

Из корня reverse-c2-research выполнить команды, указав свой путь к исходной поставке. Они читают файлы и не запускают сборки продукта. Вторая команда выводит новый JSON-аудит в stdout.

```bash
python research/validation/continuation/verify.py /absolute/path/to/distribution
python research/validation/continuation/audit_evidence.py
PYTHONDONTWRITEBYTECODE=1 python research/validation/continuation/test_retained_evidence.py
```
