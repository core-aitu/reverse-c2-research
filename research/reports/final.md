# SpecterInsight 7.0.0 — результаты исследования локальной поставки

**Последнее обновление.** Один идентификатор события проверен в PostgreSQL, на локальном SignalR-соединении, в коллекции штатной ViewModel и в видимом тексте открытого EventLogControl. Для пяти разных образов Beacon добавлены 65 индивидуальных разборов методов диагностической записи. Текущий нижний предел индивидуального покрытия — **121 пара «образ–метод»**. Таблицы ниже сохраняют исходные итоги предыдущего этапа, в том числе его счётчик 56. Положительный доступ к подлинному защищённому Management API, штатное восстановление соединения и сетевое поведение Beacon остаются открытыми. [Результаты этапа](../validation/continuation/results.md) · [Матрица](../validation/continuation/matrix.json) · [Реестр задач](../validation/continuation/backlog.md)


**13 ноября 2026 года.** Ресурсы PE четырёх основных сборок — Server, Server.Host, UI и ApiClient — указывают версию продукта **7.0.0**. Для этих файлов версия подтверждена непосредственно. Идентичность локального дерева эталонному релизу производителя установить не удалось. Для документации, журнала событий, справочника производителей и части представления UI статический разбор сопоставлен с исполнением поставленных сборок. Для одного варианта Beacon проверена связь с поставляемым исходным текстом. [Версии файлов](../evidence/pe-versions.json) · [Реестр выводов](../validation/findings.jsonl)

## Что подтверждено об архитектуре

**Клиент и сервер имеют отдельные точки запуска.** Файл рабочего стола указывает на UI, служба systemd — на Server.Host. В IL клиента видны построение приложения Avalonia и передача управления циклу настольного приложения. В Host асинхронный Main вызывает серверный метод Build, затем WebApplication.RunAsync. Независимый разбор REA подтвердил MVID и токен точки входа Host. Манифест Server объявляет .NET 8, а Host и UI — .NET 10. [Представления архитектуры](../architecture/views.md) · [Свидетельство REA](../examination/rea-host-summary.json)

**Сервер регистрирует контроллеры и SignalR и включает авторизацию в конвейер.** В выбранных серверных типах и методах найдено 182 объявления AuthorizeAttribute. В Compose объявлены PostgreSQL, Elasticsearch и Kibana. В коде создания таблицы поисковых фрагментов есть DDL с уникальным индексом по паре Path и ChunkIndex. Эти свидетельства устанавливают устройство исследованного кода. Для установления политики доступа конкретного пользователя, применённых миграций и состояния таблиц нужны наблюдения работающей установки. [Справочник Server](../components/server/reference.md) · [Модель хранения](../analysis/storage.md)

**Версия и имя файла недостаточны для идентификации Specter.** Серверный SpecterInsight.exe и шаблон specter-dotnet-exe.exe совпадают побайтно. Другой SpecterInsight.exe в дереве шаблонов имеет иной SHA-256 и MVID. В первом образе 710 определений методов, во втором 707. Ресурсы обеих версий EXE относятся к линии 1.0.0. Таким образом, для повторения анализа варианта нужен хеш конкретного файла. [Справочник Specter](../components/specter/reference.md) · [Группы одинаковых файлов](../evidence/duplicate-content.jsonl.gz)

## Изолированный опыт с документацией

Серверная DLL прочитала синтетическую папку с Markdown. Стенд передал результат штатному ApiClient через HTTP-обработчик в памяти и передал декодированные узлы штатной ViewModel. В каждом из двух основных прогонов и отдельном контрольном прогоне прошли **8 из 8 проверок**. Три журнала совпали побайтно. Границы опыта — загрузчик серверной DLL, клиентская обработка ответа и поиск узла в модели. Сетевой сервер, БД, Specter и графическое окно не запускались. [Сценарий и границы](../interactions/documentation.md) · [Контрольный журнал](../validation/documentation/run-control.jsonl) · [Среда](../validation/environment.json)

| Наблюдение | Результат |
|---|---|
| Чтение папки и отсутствующего каталога | Текст Overview.md стал содержимым папки и сохранился отдельным дочерним узлом Overview. Для отсутствующего каталога получен пустой массив. |
| Успешные ответы клиента | Клиент сформировал GET /Documentation, разобрал вложенное дерево при 200 и принял пустой массив. |
| Два ошибочных ответа | При 200 с JSON null и при 503 клиент завершил вызов исключением ApiException. |
| Поиск в модели UI | Для Guide/Sample вернулся исходный Markdown, для Guide/Missing — null. |

**Роль ИИ в исследовании.** ИИ формулировал гипотезы, выбирал точки наблюдения и подготовил стенд. Первоначальное ожидание, что Overview.md используется *только* как описание папки, оказалось ошибочным. Сервер вернул одновременно описание папки и дочерний документ. Утверждение сохранено со статусом Contradicted, а проверка обеих ролей вошла в повторяемый опыт.
