# Server и Server.Host

| Свойство | Свидетельство и вывод |
|---|---|
| Запуск | В systemd указан Host. В CLI-заголовке Host задана точка входа 0x06000003. Её IL вызывает Main. В теле асинхронного автомата 0x06000004 есть обращения к серверному Build и WebApplication.RunAsync. Два независимых анализатора совпали по MVID и токену входа. FND-004, FND-005. |
| Регистрация служб | В ConfigureServices есть операнды AddSingleton, AddScoped, AddSignalR, AddControllers. В Configure есть UseRouting, UseAuthorization и UseEndpoints. Метаданные содержат 182 объявления AuthorizeAttribute на обследованной группе контроллеров и их методов. Это число атрибутов. Эффективная политика по запросу и решения об отказе требуют отдельного наблюдения. FND-012. |
| Административный запрос | DocumentationController имеет шаблон маршрута [controller]. Получение дерева передаёт работу асинхронному загрузчику. Для синтетической папки проверены чтение, образование дочерних элементов и поведение при отсутствии каталога. Динамический вход теста — метод Load. FND-006, FND-007. |
| Хранение и поиск | В пространстве имён Database.Entities обнаружены 33 определения типа. Для DocumentationChunk найдены CLR-свойства, DDL и вызов ExecuteNonQueryAsync. Данных об исполнении этого DDL в конкретной установке нет. FND-011. |
| События и фоновая работа | В сборке есть EventLoggingService и SpecterEventHub. Документация связывает запись событий в PostgreSQL с уведомлениями SignalR и экраном клиента. Регистрация SignalR подтверждена IL. Запись события в лабораторную БД и вызов интерфейса SignalR проверены в отдельном опыте. Сетевая доставка в действующей установке остаётся гипотезой. FND-013. |

В манифесте автономной Server указан .NET 8, в Host — .NET 10. В изолированном опыте метод из Server работал внутри процесса .NET 10. Это наблюдение относится к исследованному методу и конфигурации опыта. FND-003, FND-007.
