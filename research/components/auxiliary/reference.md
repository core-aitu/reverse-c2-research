# Дополнительные части поставки

| Группа | Что найдено | Что этим подтверждается |
|---|---|---|
| dependencies | 142 286 файлов. Среди них bflat, дерево Zig, библиотеки нескольких поколений .NET, коллекция текстов и наборы данных JSON. | Физическое присутствие. Точки использования библиотек устанавливаются отдельно по AssemblyRef и графам манифестов. |
| documentation | 53 файла Markdown. | Происхождение встроенного руководства. Синтетический опыт отдельно проверяет модель чтения такого дерева. |
| elastic | Экспорт NDJSON с 28 визуализациями, 6 панелями, 5 поисками, 2 шаблонами индексов, 2 картами и 1 служебной записью. | Комплект для визуализации. Его импорт в Kibana не наблюдался. |
| notebooks и архивы | Пять файлов в notebooks. Во всей поставке по сигнатуре обнаружено восемь ZIP-контейнеров, в них 82 элемента. Три элемента помечены шифрованными. | Для открытых элементов вычислены хеши содержимого. Для шифрованных сохранены имена, размер из заголовка и хеш внешнего контейнера. |
| settings, resources, assets | Два экземпляра настроек в поставке и в дереве VM. В обоих разделы Database и Elastic. Среди ресурсов присутствуют геобаза MMDB, таблица производителей и SVG. | Реестр сохраняет расположение и хеш. В отчёт по настройкам включены только имена полей. |
| vm, webdav | Дескрипторы запуска, описание инфраструктуры и пустые каталоги WebDAV. | Макет развёртывания и места в дереве. По пустому каталогу нельзя установить активность сетевой службы. |

Все строки опираются на OBS-001 и OBS-010. Для развёртывания также используется OBS-004. [Состав по каталогам](../../examination/distribution.json) · [Элементы архивов](../../evidence/archive-members.json) · [Пакеты](../../architecture/package-graphs.json)
