# Метаданные 22 файлов modules

Все 22 файловых хеша совпали с исходным каталогом. В таблицах метаданных этих файлов в сумме 14 009 определений методов и 1 295 публичных типов верхнего уровня. Столбец `exported_type_table_rows` относится к отдельной таблице CLI ExportedType. Во всех файлах она пуста. Публичность объявленных в сборке типов измерялась по флагу TypeDef.Public. [Данные для каждого файла](result.json)

В девяти сборках нет ни одной строки InterfaceImpl. Таким образом, гипотеза о наличии явной записи об реализации общего интерфейса в каждом из 22 файлов противоречит метаданным. Наследование реализации, различия между библиотеками и модулями, а также фактическая загрузка в определённом процессе требуют других свидетельств. У семи файлов есть кандидаты на потребителя по AssemblyRef из предыдущей проверки. Число записей MethodDef ничего не сообщает о запущенных методах. [Предыдущая инвентаризация по именам сборок и ссылкам](../../validation/continuation/variants-and-modules.json)

Для повторения передайте путь к поставке как единственный аргумент скрипта. Он читает PE/CLI через dnfile, сверяет перечень файлов и SHA-256, выводит JSON в stdout. [Скрипт](read_modules.py)
